## 🧪 Research & Missions

**MSc Dissertation** — *Evaluating Prompt Injection Attacks Against AI-Powered SOC Assistants* (in progress)
- Investigating how prompt injection manipulates AI-powered SOC assistants and induces hallucinated outputs, in a simulated SOC environment.

**BSc Dissertation** — *Automated Cybersecurity Event Analysis* (Grade: High Honors)
- Co-designed an automated event analysis system integrating multiple security tools for incident detection and investigation.

**Applied Cryptography Project** — *Reverse Engineering Cryptographic Obfuscation in Ransomware Executables* (Grade: High Honors)
- Built a Java ransomware simulation using AES-GCM and PBKDF2, then analysed it with Ghidra and IDA Pro.

**Penetration Testing Project** — *LLM-Assisted File Prioritisation for Simulated Ransomware Exfiltration* (Grade: Honors)
- Compared AI-assisted file classification against rule-based approaches using precision/recall, surfacing LLMs' practical limits for security automation.
